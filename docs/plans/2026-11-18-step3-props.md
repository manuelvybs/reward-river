# Twin Moon River — Step 3 (props) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the greybox placeholders with generated 3D props, three at a time, each approved by Manuel as a 2D concept first.

**Architecture:** Concepts on fal (`fal-ai/nano-banana-pro`, or `/edit` with the astronaut refs when the prop borrows the mascot's shapes), one object per image on plain light grey, 3/4 view, warm golden-hour palette, stylized hand-painted 3D game-asset look. The pick goes to `tripo3d/h3.1/image-to-3d` (texture on, PBR off, face limit per prop). `tools/slim-prop.sh` resizes textures to webp and keeps the GLB small. `src/props.js` loads `assets/models/<name>.glb`, normalizes size/pivot from a per-prop spec (target size, ground offset, yaw) and hands the instance to `world.js`, which keeps its placeholder when a GLB is missing.

**Batches (concept → pick → 3D → in game):**
1. `helmet-face` (the two chasm statues), `tree` (trunk + branch to the rope anchor), `raft` (pod-raft, oars stay procedural)
2. `bust` (half-sunken river helmets), `crystal` (pillars), `antenna` (the duck beam)
3. `cliff` (wall chunks), `boulders`, `arch` (crashed-rocket arch)

**Per batch:**
- [ ] write the three prompts to `tools/prompts/prop-<name>.json`, run them in parallel (2 variants each), contact sheet to Manuel
- [ ] Manuel picks one per prop (or asks for a re-roll)
- [ ] Tripo image-to-3d on each pick; inspect (tris, texture); headless look in `tools/hero-viewer.html?glb=` (static)
- [ ] slim, add the spec to `src/props.js`, wire into `world.js`, keep the gameplay colliders unchanged
- [ ] `npm test` + `node tools/playtest.mjs` (0 errors, lagoon reached), beat screenshots to Manuel
