# Twin Moon River — Step 1 (rigged astronaut hero) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `assets/models/hero.glb`: the VYBS astronaut as a rigged, textured, game-weight GLB carrying every animation clip the game needs, approved by Manuel.

**Architecture:** One small fal queue client (`tools/fal.mjs`) runs every generation and logs it to `tools/fal-log.jsonl`. The hero goes four clean views (Nano Banana Pro) → multiview-to-3D (Tripo) → auto-rig plus 10 library clips (Meshy) → one merged, slimmed GLB (glTF-Transform) → a viewer page for review. Manuel approves at two checkpoints: the four views, then the rigged hero.

**Tech Stack:** Node 25 (built-in fetch, `node:test`), fal queue REST API, `@gltf-transform/core|extensions|functions|cli` 4.x, three.js 0.187.0 (vendored, no build step), ImageMagick for crops.

Spec: `docs/specs/2026-11-18-twin-moon-river-design.md`.

```js
// Minimal fal queue client. Every call is appended to tools/fal-log.jsonl (endpoint, label, input, urls).
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const HERE = path.dirname(fileURLToPath(import.meta.url));
const LOG = path.join(HERE, 'fal-log.jsonl');
const MIME = { png: 'image/png', jpg: 'image/jpeg', jpeg: 'image/jpeg', webp: 'image/webp', glb: 'model/gltf-binary', mp3: 'audio/mpeg', wav: 'audio/wav' };

const urlsIn = o => JSON.stringify(o).match(/https:\/\/[^"]+/g) || [];
const sleep = ms => new Promise(r => setTimeout(r, ms));

export async function run(endpoint, input, label, o = {}) {
  const f = o.fetch || fetch, key = o.key || process.env.FAL_KEY, pollMs = o.pollMs ?? 3000;
  const H = { Authorization: `Key ${key}`, 'Content-Type': 'application/json' };
  const t0 = Date.now();
  const sub = await (await f(`https://queue.fal.run/${endpoint}`, { method: 'POST', headers: H, body: JSON.stringify(input) })).json();
  if (!sub.request_id) throw new Error(`submit failed: ${JSON.stringify(sub).slice(0, 400)}`);
  for (;;) {
    const st = await (await f(sub.status_url, { headers: H })).json();
    if (st.status === 'COMPLETED') break;
    if (st.status === 'FAILED' || st.error) throw new Error(`FAILED ${endpoint}: ${JSON.stringify(st).slice(0, 400)}`);
    await sleep(pollMs);
  }
  const res = await (await f(sub.response_url, { headers: H })).json();
  if (res.detail) throw new Error(`FAILED ${endpoint}: ${JSON.stringify(res.detail).slice(0, 400)}`);
  fs.appendFileSync(o.logFile || LOG, JSON.stringify({ t: new Date().toISOString(), label, endpoint, request_id: sub.request_id,
    secs: Math.round((Date.now() - t0) / 1000), input, urls: urlsIn(res) }) + '\n');
  return res;
}

export async function upload(file, o = {}) {
  const key = o.key || process.env.FAL_KEY;
  const content_type = MIME[path.extname(file).slice(1).toLowerCase()] || 'application/octet-stream';
  const init = await fetch('https://rest.alpha.fal.ai/storage/upload/initiate', { method: 'POST',
    headers: { Authorization: `Key ${key}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ file_name: path.basename(file), content_type }) });
  if (!init.ok) throw new Error(`upload initiate ${init.status}: ${(await init.text()).slice(0, 300)}`);
  const { upload_url, file_url } = await init.json();
  const put = await fetch(upload_url, { method: 'PUT', headers: { 'Content-Type': content_type }, body: fs.readFileSync(file) });
  if (!put.ok) throw new Error(`upload put ${put.status}`);
  return file_url;
}

export async function download(url, out) {
  const r = await fetch(url);
  if (!r.ok) throw new Error(`download ${r.status} ${url}`);
  fs.mkdirSync(path.dirname(out), { recursive: true });
  fs.writeFileSync(out, Buffer.from(await r.arrayBuffer()));
  return out;
}

// CLI: node tools/fal.mjs <endpoint> <input.json> <label>
if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const [endpoint, inputFile, label] = process.argv.slice(2);
  const res = await run(endpoint, JSON.parse(fs.readFileSync(inputFile, 'utf8')), label || path.basename(inputFile));
  console.log(JSON.stringify(res, null, 2));
}
```

```js
// node tools/inspect-glb.mjs file.glb [--expect-clips a,b,c]
import { NodeIO } from '@gltf-transform/core';
import { ALL_EXTENSIONS } from '@gltf-transform/extensions';
import fs from 'node:fs';
const [file, flag, list] = process.argv.slice(2);
const doc = await new NodeIO().registerExtensions(ALL_EXTENSIONS).read(file);
const root = doc.getRoot();
let tris = 0;
for (const m of root.listMeshes()) for (const p of m.listPrimitives()) {
  const idx = p.getIndices(); tris += (idx ? idx.getCount() : p.getAttribute('POSITION').getCount()) / 3;
}
const bones = root.listSkins().flatMap(s => s.listJoints().map(j => j.getName()));
const clips = root.listAnimations().map(a => {
  const d = Math.max(0, ...a.listSamplers().map(s => s.getInput().getMax([])[0] ?? 0));
  return `${a.getName()} (${d.toFixed(2)}s)`;
});
const tex = root.listTextures().map(t => `${t.getMimeType()} ${t.getSize()?.join('x')} ${(t.getImage().byteLength / 1024).toFixed(0)}KB`);
console.log(JSON.stringify({ file, MB: +(fs.statSync(file).size / 1e6).toFixed(2), meshes: root.listMeshes().length, tris: Math.round(tris),
  bones: bones.length, boneNames: bones, clips, textures: tex }, null, 2));
if (flag === '--expect-clips') {
  const have = new Set(root.listAnimations().map(a => a.getName()));
  const miss = list.split(',').filter(c => !have.has(c));
  if (miss.length) { console.error('MISSING clips:', miss.join(', ')); process.exit(1); }
  console.error('all clips present');
}
```

```js
// node tools/merge-hero.mjs <rigged.glb> <out.glb> name=clip.glb [name=clip.glb ...]
// Copies the first animation of each clip GLB into the rigged GLB under `name`, matching target nodes by name.
import { NodeIO } from '@gltf-transform/core';
import { ALL_EXTENSIONS } from '@gltf-transform/extensions';
import { prune, dedup } from '@gltf-transform/functions';
const [riggedPath, outPath, ...pairs] = process.argv.slice(2);
const io = new NodeIO().registerExtensions(ALL_EXTENSIONS);
const doc = await io.read(riggedPath);
const root = doc.getRoot();
const buffer = root.listBuffers()[0] || doc.createBuffer();
const byName = new Map(root.listNodes().map(n => [n.getName(), n]));
for (const a of root.listAnimations()) a.dispose();
for (const pair of pairs) {
  const [name, file] = pair.split('=');
  const src = (await io.read(file)).getRoot().listAnimations()[0];
  if (!src) throw new Error(`no animation in ${file}`);
  const anim = doc.createAnimation(name);
  let n = 0;
  for (const ch of src.listChannels()) {
    const target = byName.get(ch.getTargetNode()?.getName());
    if (!target) continue;
    const s = ch.getSampler();
    const input = doc.createAccessor().setType('SCALAR').setArray(s.getInput().getArray().slice()).setBuffer(buffer);
    const output = doc.createAccessor().setType(s.getOutput().getType()).setArray(s.getOutput().getArray().slice()).setBuffer(buffer);
    const sampler = doc.createAnimationSampler().setInput(input).setOutput(output).setInterpolation(s.getInterpolation());
    anim.addSampler(sampler).addChannel(doc.createAnimationChannel().setTargetNode(target).setTargetPath(ch.getTargetPath()).setSampler(sampler));
    n++;
  }
  if (!n) throw new Error(`${name}: no channel matched a node of the rig`);
  console.error(`${name}: ${n} channels`);
}
await doc.transform(dedup(), prune());
await io.write(outPath, doc);
```

## As built (2026-11-18)

- **Views:** 4:1 was rejected by the provider; generated 21:9, cut along the real background gaps (equal-width crops clipped a mitten), mirrored panel 2 into a true left view.
- **Third sparkle:** Tripo projected the side views' sparkle onto the visor front. Fixed by filling the sparkle hole in both side views with blurred local indigo, then re-running Tripo.
- **Orientation:** Tripo's mesh faces +X; Meshy fitted its skeleton 90° off (hand joint in front of the belly). `tools/rotate-glb.mjs` bakes -90° about Y so the mesh faces +Z before rigging. The shipped hero faces +Z.
- **Skin weights:** Meshy's auto-weights mixed unrelated limbs on 33% of vertices (mittens next to thighs, helmet underside next to shoulders) and tore the mesh. `tools/reweight-hero.mjs` replaces them: geodesic (along-the-surface) weights limited to bone/parent/child, a rigid helmet on `Head` above the collar, and the lower torso on `Hips` above the hip joints. Cross-limb vertices 5,605 → 436 (chest blending only).
- **Clips:** Meshy idle 0 turns the body sideways; replaced by **idle = 243 (Idle_3)** from a second call, which also added **wave = 28 (Big_Wave_Hello)** for the title screen. The second call's skeleton matched the first within 0.4 cm, so its clips merge onto the same rig. 13 clips: idle, wave, run, walk, jump, throw, hang, swing, fall, land, sit, sitCheer, cheer.
- **Slimming:** `gltf-transform optimize` breaks the skinning (one of its join/weld/flatten steps); `tools/build-hero.sh` uses resample + resize 2048 + webp only. Result 1.79 MB, 28.7k tris, 24 bones.
- **Rebuild:** `tools/build-hero.sh` (needs the local Meshy outputs in `art-src/hero/meshy*/`, which are not committed).
- **fal spend for step 1:** Nano Banana Pro ×2 images, Tripo multiview ×2, Meshy rig+clips ×3.
