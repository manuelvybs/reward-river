# Twin Moon River — Step 4 (paint: textures, backdrops, atlases) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the flat vertex colours with painted surfaces, add painted far backdrops and scattered foliage/foam sprites, keeping the warm golden-hour look.

**Architecture:**
- `fal-ai/nano-banana-pro` generates everything (Manuel reviews the whole set once, re-rolls on request).
- Textures: `tools/make-tileable.sh` (offset by half + feathered cross blend) → 1024 webp in `assets/tex/`.
- Backdrops: painted on plain white, keyed to alpha (`tools/key-white.sh`) → `assets/backdrops/*.webp`; drawn on a camera-following arc behind everything (fog off), canyon on foot, colony on the river, crossfaded by progress.
- Terrain: one `terrainMaterial()` (MeshStandardMaterial + onBeforeCompile) blends base / alt / moss textures by vertex colour (r = brightness, g = moss weight, b = alt weight); world-space UVs per mesh.
- Sprites: 2×2 atlases keyed to alpha → `assets/sprites/`; foliage as instanced crossed quads along the trail and banks, foam as flat quads at the drops and around river obstacles.

**Tasks:**
- [ ] prompts `tools/prompts/paint-*.json`, run in parallel, contact sheet → Manuel
- [ ] tile / key / slice; check seams by tiling 2×2
- [ ] `src/paint.js` (load textures, terrainMaterial, atlases); `main.js` awaits it before `buildWorld`
- [ ] world: UVs + terrain materials for walls, floors, banks; stone on steps/quay/ruins; water texture; backdrops replace the procedural mesas
- [ ] foliage + foam sprites
- [ ] `npm test`, `node tools/playtest.mjs`, beat screenshots → Manuel
